# **详情**：

## 1. 总体架构 + 撰稿 + 音频前期处理：

写 preprocess.py：

*   **功能**：读取音频，幅度归一化，计算帧长和帧移，进行分帧。
*   **输入参数**：
    *   `audio_path` (str): wav文件路径。
    *   `frame_ms` (float): 帧长（毫秒），默认25。
    *   `hop_ms` (float): 帧移（毫秒），默认10。
*   **返回值 (Dictionary)**：
    返回一个字典，包含后续处理所需的**全部上下文信息**，避免下游重复计算
    *   `y_raw` (1D Array): 一维 NumPy 数组, 归一化（除以最大绝对值）后的原始一维音频信号。**（关键：音符分割最终需要切这个数组）**
    *   `frames` (2D Array): 二维 NumPy 数组, 分帧矩阵，形状为 `(帧数, 帧长)`。
    *   `sr` (int): 采样率。
    *   `frame_len` (int): 帧长对应的采样点数。
    *   `hop_len` (int): 帧移对应的采样点数。



维护 main_demo.py 主流程



## 2. 音频时域处理
写 segment_notes.py:
*   **功能**：根据分帧矩阵计算短时能量和过零率，通过阈值判定起止点，从原始信号中切出单音。
*   **输入参数**：
    *   `data_dict` (dict): 模块1的输出字典。
*   **返回值 (List of 1D Arrays)**：
    *   `notes_list` (list): 包含切分出的所有单音信号。列表中的每个元素是一个一维 NumPy 数组（如 `[np.array([...]), np.array([...])]`）。

## 3.Goertzel 算法与离散谱线归一化
写calc_goertzel_spectrum.py：
*   **功能**：利用 Goertzel 算法计算单音信号在 26 个标准音基频处的频谱幅度，并进行能量归一化（参考图3.1）。
*   **输入参数**：
    *   `note_signal` (1D Array): 单个音符的一维音频信号。
    *   `sr` (int): 采样率。
    *   `target_freqs` (1D Array): 26个标准音的基频列表，例如 `[261.63, 277.18, ..., 440.0]`，长度为 M=26。
*   **返回值 (1D Array)**：
    *   `S_i` (1D Array):一维 NumPy 数组， **归一化后的离散频谱序列**。长度 \(N=26\)。

## 4. 匹配滤波器与结果判决：
写match_filter_decision.py
*   **功能**：将输入序列与 26 个标准音模板进行卷积/相关运算（根据图3.2及后续推导，滤波器在 n=N-1 处的采样输出，完全等价于两个序列的点积（内积）），采样输出并寻找最大值（参考图3.2）。
*   **输入参数**：
    *   `S_i` (1D Array): 模块3输出的输入信号归一化频谱序列。
    *   `templates` (2D Array): 标准音模板矩阵（每个标准音输入模块3得到），形状为 `(M, N)` 即 `(26, 26)`。每一行是一个标准音的归一化频谱 \(S_j\)。
*   **返回值 (Tuple)**：
    *   `best_note_idx` (int): 匹配度最高的标准音索引（0-25）。
    *   `max_corr_value` (float): 最大的相关系数值（用于置信度判断）。



**重点：**

1.  **维度对齐**：强调模块1负责输出二维矩阵，模块2负责降维输出一维数组列表，模块3输出固定长度（如26）的一维数组，模块4输出标量。
2.  **归一化**：模块1的音频归一化（除最大值）和模块3的频谱归一化（L2范数除法）必须严格按照公式执行，否则模块4的相关系数会失去意义（无法满足 \(r_i \ge r_j\) 的证明前提）。
