## 1. 论文内容总结

### 1.1 基本信息

| 项目 | 内容 |
|---|---|
| 题目 | 基于频域匹配滤波的音频信号分析与识别 |
| 作者 | 赵凌览，李晓峰（电子科技大学信息与通信工程学院） |
| 期刊 | 实验科学与技术，2018，16(5)：34-38 |
| DOI | 10.3969/j.issn.1672-4550.2018.05.008 |
| 关键词 | 音频识别；端点检测；时频转换；匹配滤波 |
| 核心思想 | 用 Goertzel 得到音符的稀疏离散谱线，做成能量归一化模板；待测信号频谱与各模板做匹配滤波（相关），取最大相关对应的音符 |

### 1.2 论文解决什么问题

乐音识别是自动记谱、音乐检索、计算机辅助作曲的基础。已有方法通常只保留基频、滤除泛音，再识别基频。这样虽然可行，但丢弃了泛音信息，抗噪性和可靠性会下降。

论文的改进点有两个：

1. **保留并利用泛音**：模板不只包含基频，还包含谐波形成的频谱结构，因此不同音色、不同噪声条件下更稳。
2. **用 Goertzel 代替完整 FFT**：只在可能出现谱峰的那些频率上计算单一谱线，降低运算量，同时保留识别所需信息。

### 1.3 方法总览（复现时按这五步走）

```
标准音录音 ──► 端点检测 ──► Goertzel ──► L2 归一化 ──► 模板矩阵 S (N×M)
                                                              │
待测音频 ──► 归一化 ──► 分帧 ──► 端点检测 ──► 单音分割          │
                                                              ▼
                     Goertzel 谱向量 ──► L2 归一化 ──► 与 M 个模板做相关
                                                              │
                                                              ▼
                                                         最大值判决 ──► 单音识别
```

论文里对应的描述：

1. 对音频所有采样点幅度归一化；
2. 利用乐音短时平稳性分帧，用短时能量和短时过零率判断单音起止；
3. 对每个标准音，用 Goertzel 得到离散谱线序列，并做能量归一化；
4. 将归一化序列翻转、时移，构成 M 路匹配滤波器；
5. 待测单音的谱序列并行通过 M 路滤波器，在 n=N−1 处采样，取输出最大的一路作为识别结果。

### 1.4 关键公式（报告和答辩都要用）

**（1）Goertzel 单频点计算**

对长度 N 的序列 x[n]，目标频率 ω₀=2πf₀/f_s：

$$
s[n]=x[n]+2\cos\omega_0\,s[n-1]-s[n-2],\qquad s[-1]=s[-2]=0
$$

$$
X(\omega_0)=s[N-1]-e^{-j\omega_0}s[N-2]
$$

$$
|X(\omega_0)|^2=s[N-1]^2+s[N-2]^2-2\cos\omega_0\,s[N-1]s[N-2]
$$

它对应的系统函数是二阶 IIR：

$$
H(z)=\frac{1-e^{-j\omega_0}z^{-1}}{1-2\cos\omega_0\,z^{-1}+z^{-2}}
$$

> 答辩点：Goertzel 不是“近似 FFT”，而是对单个频点的 DFT 做递推计算；每个频点 O(N)，只需要少量频点时比 FFT 的 O(N log N) 更省。

**（2）模板能量归一化**

$$
\bar S_j[n]=\frac{S_j[n]}{\|S_j\|_2},\qquad
\|S_j\|_2=\sqrt{\sum_{n=0}^{N-1}S_j^2[n]}
$$

**（3）匹配滤波器**
$$
h_j[n]=\bar S_j[N-1-n]
$$

**（4）在 n=N−1 处采样，等价于相关**

$$
y_j[N-1]=\sum_{k=0}^{N-1}\bar S_i[k]\,h_j[N-1-k]
=\sum_{k=0}^{N-1}\bar S_i[k]\,\bar S_j[k]
=r_{ij}[0]
$$

**（5）为什么正确音符一定得分最高**

由 Cauchy–Schwarz 不等式：

$$
r_{ij}\le 1=r_{ii}
$$

所以，当输入谱向量与某个模板完全一致时，该路输出为 1，其他路不超过 1。实际中取最大相关对应的模板即可。前提是**输入谱向量和模板都做了 L2 归一化**；如果只归一化模板、不归一化输入，这个上界不成立，判决会受音量影响。

### 1.5 论文给出的结果

| 实验 | 结果 |
|---|---|
| 单音相关矩阵（C4–B4 的 7 个自然音，不含半音） | 对角线 0.909–0.999；非对角线大多 <0.14，最大约 0.140 |
| 和弦 C4–E4–G4 分解 | E4 0.7062、C4 0.5691、G4 0.3763，前三名正好是三个和弦音 |
| 乐句《Mary Had a Little Lamb》前 7 音 | E4、D4、C4、D4、E4、E4、E4，与乐谱一致 |
| 抗噪（20 音 ×10 次 = 200 次检测） | 20/15/10 dB 错检 0；5 dB 错检 2 次（1.0%）；0 dB 错检 9 次（4.5%） |

论文的结论：频域匹配滤波利用了泛音，识别可靠性和抗噪性较好；Goertzel 只算少量谱线，复杂度低。

**关于频率网格的两个方案：**

- **方案 A（忠实论文，推荐先做）**：网格就是 26 个音符基频，N=26。二次谐波恰好落在高八度的音上（如 C4# 的 2 次谐波 554.36 Hz ≈ C5#），三次谐波落在十二度附近（如 831.5 Hz ≈ G5#），所以“只取基频网格”其实也间接采到了泛音，这正是论文用少量谱线仍能利用泛音的原因。

### 4.4 算法伪代码

**单音：**

```matlab
function [idx, scores, best] = recognize_single(x, fs, T, p)
    x = x(:);
    x = x / (max(abs(x)) + eps);
    S = goertzel_mag(x, fs, T.grid);   % N×1
    S = S / (norm(S) + eps);           % 输入也要归一化
    scores = T.S' * S;                 % M×1，等价匹配滤波在 n=N-1 采样
    [best, idx] = max(scores);
    if best < p.min_score
        idx = 0;                       % 判为静音/不确定
    end
end
```

**乐句：**

```matlab
function [notes, segs] = recognize_phrase(x, fs, T, p)
    segs = segment_notes(x, fs, p);
    notes = strings(1, numel(segs));
    for k = 1:numel(segs)
        [idx, scores, best] = recognize_single(segs(k).x, fs, T, p);
        if idx == 0
            notes(k) = "rest";
        else
            notes(k) = string(T.names{idx});
        end
    end
end
```

### 4.6 课程理论映射（答辩必问）

| 课程概念 | 在项目中的体现 | 一句话解释 |
|---|---|---|
| 卷积 | 匹配滤波器输出 y[n]=x[n]*h[n] | 滤波器冲激响应是模板翻转，输出是加权叠加 |
| 系统函数 | Goertzel 的 H(z)、匹配滤波的 H(z) | 二阶 IIR 的极点决定单频选择性；匹配滤波在 z 域是模板的反转/时移 |
| 零输入/零状态响应 | Goertzel 递推初值为 0 | 我们算的是零状态响应；有限长处理不存在不稳定发散 |
| 频谱分析 | DFT/Goertzel、采样定理、频率分辨率 | Δf=f_s/N；窗长决定分辨率，窗函数减小泄漏 |
| 滤波 | 匹配滤波、相关检测 | 白噪声下匹配滤波使采样时刻 SNR 最大 |
| 能量/Parseval | L2 归一化、相关上界 | 归一化后 rᵢᵢ=1，Cauchy–Schwarz 保证正确模板最大 |
| 抽样定理 | fs > 2fmax | 保留到至少 3 次谐波；C6 的 3 次谐波约 3.1 kHz，44.1 kHz 足够 |

## 8. 验收演示脚本（5–7 分钟）

### 8.1 答辩可能被问的问题

| 问题 | 回答要点 |
|---|---|
| 为什么用 Goertzel 不用 FFT？ | 只需要 27 个频点；Goertzel 每点 O(N)，FFT 全谱 O(N log N)；稀疏频谱更省，且可任意频点 |
| 为什么在 n=N−1 采样？ | 匹配滤波冲激响应是模板翻转；N 点序列卷积在 N−1 处对齐，输出正好是内积/相关 |
| 为什么要能量归一化？ | 消除音量影响；归一化后自相关为 1，Cauchy–Schwarz 保证正确模板最大 |
| 匹配滤波和相关的区别？ | 本质等价；匹配滤波是 LTI 滤波 + 采样，相关是翻转平移的内积；h[n]=S[N−1−n] 把两者联系起来 |
| Goertzel 的系统函数？ | H(z)=(1−e^{−jω₀}z^{−1})/(1−2cosω₀ z^{−1}+z^{−2})；极点在单位圆上，有限长处理 |
| 零输入/零状态响应？ | 递推初值为 0，算的是零状态响应；没有零输入分量 |
| 为什么保留泛音？ | 泛音决定音色；不同音符的谐波结构不同；噪声下比单看基频稳 |
| 噪声这么大为什么还能识别？ | 白噪声在频域分散，相关运算把模板方向的能量累积；时域波形失真不等于频谱结构消失 |
| 低音区为什么难？ | 基频间隔小（B3 附近约 15 Hz），需要更长窗提高分辨率；窗太短会糊 |
| 会不会把八度认错？ | 有可能；二次谐波落在高八度，模板里也有该分量；用完整谱模板 + 阈值/相对差抑制；报告里给混淆矩阵 |
| 和弦怎么定 top-3？ | 相关分数排序；加绝对阈值和相对差；纯 top-3 在强泛音时可能误判 |
| 实时性如何？ | 27 频点 × 段长；单音几十毫秒级；GUI 录音后处理，交互延迟 <1 s |
| 怎么改进行？ | 谱通量/能量联合端点检测、NMF/深度学习复音转录、自适应模板、节拍/时值、嵌入式实现 |

## 附录 A：MATLAB 代码骨架

### A.1 Goertzel 单频点

```matlab
function mag = goertzel_mag(x, fs, freqs)
% GOERTZEL_MAG 计算序列在指定频点上的幅度（单频点 DFT）
% x: 输入序列（列向量）；fs: 采样率；freqs: 频率向量（Hz）
% mag: 与 freqs 同长度的幅度向量
    x = x(:);
    N = numel(x);
    if N < 2
        mag = zeros(numel(freqs), 1);
        return;
    end
    mag = zeros(numel(freqs), 1);
    for k = 1:numel(freqs)
        w0 = 2*pi*freqs(k)/fs;
        c  = 2*cos(w0);
        % 二阶 IIR：y[n] = x[n] + c*y[n-1] - y[n-2]
        s  = filter(1, [1 -c 1], x);
        s1 = s(end);
        s2 = s(end-1);
        re = s1 - cos(w0)*s2;
        im = sin(w0)*s2;
        mag(k) = hypot(re, im);
    end
end
```

**自检：** 对单频正弦，`goertzel_mag` 的结果应与 `abs(fft(x))` 在对应频点的值一致（允许窗/非整周期误差）；用 `tests/test_goertzel.m` 固定一个例子，相对误差 <1e-6。

### A.2 分帧与端点检测（骨架）

```matlab
function [segs, info] = segment_notes(x, fs, p)
% SEGMENT_NOTES 归一化、分帧、短时能量/过零率、双阈值分割
    x = x(:);
    x = x / (max(abs(x)) + eps);

    L = max(1, round(p.frame_ms * fs / 1000));
    H = max(1, round(p.hop_ms  * fs / 1000));
    nf = max(1, floor((numel(x) - L) / H) + 1);

    E = zeros(nf,1); Z = zeros(nf,1);
    for i = 1:nf
        idx = (i-1)*H + (1:L);
        f = x(idx);
        E(i) = mean(f.^2);
        Z(i) = sum(abs(diff(f > 0))) / (2*L);
    end

    noiseE = median(E(1:min(10,nf)));
    Th = max(p.noise_factor*noiseE, p.energy_high_ratio*max(E));
    Tl = max(p.noise_factor*noiseE*0.5, p.energy_low_ratio*max(E));

    active = E > Tl;
    % 这里补：找连续段、要求段内最大值 > Th、最短时长、合并近邻
    % 输出 segs(k).x / t0 / t1
    segs = []; info.E = E; info.Z = Z; info.Th = Th; info.Tl = Tl;
end
```

> 这段故意留了“连续段合并”的空，B 负责补完整；不要直接抄一个黑箱函数，验收要能讲清双阈值和滞后逻辑。

### A.3 模板构建

```matlab
function T = build_templates(files, fs, grid, names, p)
% BUILD_TEMPLATES 从标准音文件构建归一化模板矩阵
    M = numel(files);
    N = numel(grid);
    S = zeros(N, M);
    for j = 1:M
        [x, fsj] = audioread(files{j});
        x = x(:,1);
        x = x / (max(abs(x)) + eps);
        segs = segment_notes(x, fsj, p);
        % 取能量最大的段；没有则整段
        if isempty(segs)
            seg = x;
        else
            [~, k] = max([segs.energy]);
            seg = segs(k).x;
        end
        v = goertzel_mag(seg, fsj, grid);
        S(:,j) = v / (norm(v) + eps);
    end
    T.S = S; T.grid = grid(:); T.names = names; T.fs = fs;
end
```

### A.4 单音识别

```matlab
function [idx, scores, best] = recognize_single(x, fs, T, p)
    x = x(:);
    x = x / (max(abs(x)) + eps);
    S = goertzel_mag(x, fs, T.grid);
    S = S / (norm(S) + eps);
    scores = T.S' * S;
    [best, idx] = max(scores);
    if best < p.min_score
        idx = 0;
    end
end
```
