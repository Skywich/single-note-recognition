| 核心思想 | 用 Goertzel 得到音符的稀疏离散谱线，做成能量归一化模板；待测信号频谱与各模板做匹配滤波（相关），取最大相关对应的音符 |

### 1.2 论文解决什么问题

乐音识别是自动记谱、音乐检索、计算机辅助作曲的基础。已有方法通常只保留基频、滤除泛音，再识别基频。这样虽然可行，但丢弃了泛音信息，抗噪性和可靠性会下降。

论文的改进点有两个：

1. **保留并利用泛音**：模板不只包含基频，还包含谐波形成的频谱结构，因此不同音色、不同噪声条件下更稳。
2. **用 Goertzel 代替完整 FFT**：只在可能出现谱峰的那些频率上计算单一谱线，降低运算量，同时保留识别所需信息。

### 1.3 方法总览（复现时按这五步走）

```
标准音录音 ──► 端点检测 ──► Goertzel ──► L2 归一化 ──► 模板矩阵 S (N×M)
                                                              │
待测音频 ──► 归一化 ──► 分帧 ──► 端点检测 ──► 单音分割          │
                                                              ▼
                     Goertzel 谱向量 ──► L2 归一化 ──► 与 M 个模板做相关
                                                              │
                                                              ▼
                                                         最大值判决 ──► 单音识别
```

论文里对应的描述：

1. 对音频所有采样点幅度归一化；
2. 利用乐音短时平稳性分帧，用短时能量和短时过零率判断单音起止；
3. 对每个标准音，用 Goertzel 得到离散谱线序列，并做能量归一化；
4. 将归一化序列翻转、时移，构成 M 路匹配滤波器；
5. 待测单音的谱序列并行通过 M 路滤波器，在 n=N−1 处采样，取输出最大的一路作为识别结果。

### 1.4 关键公式（报告和答辩都要用）

**（1）Goertzel 单频点计算**

对长度 N 的序列 x[n]，目标频率 ω₀=2πf₀/f_s：

$$
s[n]=x[n]+2\cos\omega_0\,s[n-1]-s[n-2],\qquad s[-1]=s[-2]=0
$$

$$
X(\omega_0)=s[N-1]-e^{-j\omega_0}s[N-2]
$$

$$
|X(\omega_0)|^2=s[N-1]^2+s[N-2]^2-2\cos\omega_0\,s[N-1]s[N-2]
$$

它对应的系统函数是二阶 IIR：

$$
H(z)=\frac{1-e^{-j\omega_0}z^{-1}}{1-2\cos\omega_0\,z^{-1}+z^{-2}}
$$

> 答辩点：Goertzel 不是“近似 FFT”，而是对单个频点的 DFT 做递推计算；每个频点 O(N)，只需要少量频点时比 FFT 的 O(N log N) 更省。

**（2）模板能量归一化**
$$
\bar S_j[n]=\frac{S_j[n]}{\|S_j\|_2},\qquad
\|S_j\|_2=\sqrt{\sum_{n=0}^{N-1}S_j^2[n]}
$$

**（3）匹配滤波器**
$$
h_j[n]=\bar S_j[N-1-n]
$$

**（4）在 n=N−1 处采样，等价于相关**

$$
y_j[N-1]=\sum_{k=0}^{N-1}\bar S_i[k]\,h_j[N-1-k]
=\sum_{k=0}^{N-1}\bar S_i[k]\,\bar S_j[k]
=r_{ij}[0]
$$

**（5）为什么正确音符一定得分最高**

由 Cauchy–Schwarz 不等式：

$$
r_{ij}\le 1=r_{ii}
$$

所以，当输入谱向量与某个模板完全一致时，该路输出为 1，其他路不超过 1。实际中取最大相关对应的模板即可。前提是**输入谱向量和模板都做了 L2 归一化**；如果只归一化模板、不归一化输入，这个上界不成立，判决会受音量影响。

### 1.5 论文给出的结果

| 实验 | 结果 |
|---|---|
| 单音相关矩阵（C4–B4 的 7 个自然音，不含半音） | 对角线 0.909–0.999；非对角线大多 <0.14，最大约 0.140 |
| 和弦 C4–E4–G4 分解 | E4 0.7062、C4 0.5691、G4 0.3763，前三名正好是三个和弦音 |
| 乐句《Mary Had a Little Lamb》前 7 音 | E4、D4、C4、D4、E4、E4、E4，与乐谱一致 |

### 4.4 算法伪代码

**单音：**

```matlab
function [idx, scores, best] = recognize_single(x, fs, T, p)
    x = x(:);
    x = x / (max(abs(x)) + eps);
    S = goertzel_mag(x, fs, T.grid);   % N×1
    S = S / (norm(S) + eps);           % 输入也要归一化
    scores = T.S' * S;                 % M×1，等价匹配滤波在 n=N-1 采样
    [best, idx] = max(scores);
    if best < p.min_score
        idx = 0;                       % 判为静音/不确定
    end
end
```

**乐句：**

```matlab
function [notes, segs] = recognize_phrase(x, fs, T, p)
    segs = segment_notes(x, fs, p);
    notes = strings(1, numel(segs));
    for k = 1:numel(segs)
        [idx, scores, best] = recognize_single(segs(k).x, fs, T, p);
        if idx == 0
            notes(k) = "rest";
        else
            notes(k) = string(T.names{idx});
        end
    end
end
```

  ：

  - `S_i` (1D Array): 模块3输出的输入信号归一化频谱序列。
  - `templates` (2D Array): 标准音模板矩阵（每个标准音输入模块3得到），形状为 `(M, N)` 即 `(26, 26)`。每一行是一个标准音的归一化频谱 (S_j)。

- 返回值 (Tuple)

  ：

  - `best_note_idx` (int): 匹配度最高的标准音索引（0-25）。
  - `max_corr_value` (float): 最大的相关系数值（用于置信度判断）。

**重点：**

1. **维度对齐**：强调模块1负责输出二维矩阵，模块2负责降维输出一维数组列表，模块3输出固定长度（如26）的一维数组，模块4输出标量。
2. **归一化**：模块1的音频归一化（除最大值）和模块3的频谱归一化（L2范数除法）必须严格按照公式执行，否则模块4的相关系数会失去意义（无法满足 (r_i \ge r_j) 的证明前提）。
